# 08. 샘플 데이터 기준 정리

`samples/` 의 내용을 구현 기준값으로 옮겨 적은 문서. **`samples/` 파일은 읽기 전용이다.**
값이 충돌하면 원본 파일이 기준이다.

모든 데이터는 가상 데모 데이터다. 발주처·기업명·성적서 번호 모두 실습용이며 민감정보가 없다.

## 0. 파일 역할

| 파일 | 역할 | 시스템에서 |
|---|---|---|
| `01_입찰공고문.pdf` | 발주처 공고 (2p) | **입력** `SourceDocument(announcement)` |
| `02_기술사양서.pdf` | 요구사항 원문 (1p) | **입력** `SourceDocument(techspec)` |
| `03_자사_제품카탈로그.md` | 자사 제품 스펙 | **지식** `KnowledgeDocument(catalog)` |
| `04_자사_인증_시험_실적.md` | 인증·시험·실적 | **지식** `KnowledgeDocument(qa)` |
| `00_실습가이드_정답표.md` | 정확도 측정 기준 | 테스트 자산 → `specs/09-acceptance-tests.md` |

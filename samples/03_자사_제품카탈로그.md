# 한빛조명(주) 제품 카탈로그

문서번호: HB-CAT-2025-02
개정일: 2025-05-10
제품군: 산업용 LED 투광등 LT 시리즈

---

## 1. 제품 개요

한빛조명(주)의 LT 시리즈는 공장, 항만, 발전소 등 산업 현장용 LED 투광등이다.
표준 모델은 LT-150(150W급)과 LT-200(200W급) 두 종이며,
설치 환경에 따라 선택사양을 적용할 수 있다.

---

## 2. LT-150 사양

### 2.1 성능

| 항목 | 사양 |
|---|---|
| 소비전력 | 140 W |
| 총 광속 | 21,500 lm |
| 광효율 | 153 lm/W |
| 색온도 | 5,700 K (주광색) |
| 연색성(CRI) | Ra 75 |
| 광각 | 120도 |
| 수명 | 60,000 시간 (L70 기준) |

### 2.2 구조

| 항목 | 사양 |
|---|---|
| 방수·방진 등급 | IP65 |
| 본체 무게 | 7.2 kg |
| 외형 크기 | 380 × 330 × 90 mm |
| 동작 온도범위 | -20℃ ~ 45℃ |
| 본체 재질 | 알루미늄 다이캐스팅 |
| 표면 처리 | 분체도장 (회색) |
| 설치 방식 | 브래킷 각도조절형 |

방수 등급은 표준 IP65이며, 해안이나 고압 세척 환경용으로
IP66 사양의 강화 하우징을 선택사양으로 공급한다.
IP66 적용 시 본체 무게가 약 1.4kg 증가하고 납기가 3주 추가된다.

### 2.3 선택사양

| 사양명 | 내용 | 영향 |
|---|---|---|
| IP66 강화 하우징 | 방수 등급 IP66 | 무게 +1.4kg, 납기 +3주 |
| 확장 온도 사양 | -30℃ ~ 55℃ 대응 | 단가 +12%, 납기 +2주 |
| 디밍 제어 | 0~10V 조광 | 단가 +8% |

## 4. 공급 조건

### 4.1 납기

표준 모델 기준 계약 후 45일. 선택사양 적용 시 항목별로 추가된다.

### 4.2 보증

납품일로부터 2년간 무상 보증한다. 소비자 과실 및 천재지변으로 인한
손상은 보증에서 제외된다.

### 4.3 제공 문서

- 제품 카탈로그 및 배광 데이터
- 시험성적서
- 설치 및 취급 설명서
